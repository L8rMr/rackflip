# RackFlip

A magazine reader for iPhone, iPad and the iPhone Duo that reads from your own [Komga](https://komga.org) server: real page curl, two-page spreads, offline issues, CBZ/PDF import and themes with character.

- Product page: https://l8rmr.github.io/rackflip/
- Privacy policy: https://l8rmr.github.io/rackflip/privacy/
- Support: [open an issue](https://github.com/L8rMr/rackflip/issues)
